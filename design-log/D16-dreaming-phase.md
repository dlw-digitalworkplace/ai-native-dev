# D16 — Dreaming phase — continuous improvement loop

- **Area:** Dreaming phase — continuous improvement loop (cross-cutting, non-linear)
- **Date:** 2026-06-25
- **Status:** Active (implemented by D30)

## Decision
**A non-linear, cross-story phase that learns from the flow's exhaust and proposes improvements to the agent-config layer.** Four parts. **(1) Emission (push, warm):** each agent emits a structured *lessons-learned* record at the end of its session — e.g. the planner after iterating on plan-PR comments, the coder/polish after a recurring style fix. The agent is the correct *warm* source because only it knows what it tried and why it iterated; this self-report is deliberately warm, exactly the kind of self-grading ruled out for *gating* (polish D7, test-writer D8) but appropriate for *emission*. **(2) Synthesis (cold dreamer):** a separate **dreamer agent** — *cold, same re-grounding contract as the reviewer (D7) / test-writer (D8) / E2E agent (D9): a fresh invocation re-grounded only from the emitted lessons + artifacts, never any agent's running context* — reviews the accumulated lessons and proposes improvements. The split is **reflect-warm / synthesize-cold**, mirroring D7/D8: warmth where it is cheap (an agent self-reporting its own session), independence where it counts (deciding what is a real, recurring pattern versus a one-off). **(3) Cadence:** runs on a regular basis; the framework leaves the exact trigger open — **e.g. every X `Implementation complete` items** (a volume-based example, not pinned, same spirit as parking N in D12). **(4) Output & authority:** every proposal lands as a **GitHub PR against `.claude`**, **one dream cycle = one PR**, which a **human accepts or rejects** — the dreamer *proposes*, the human *disposes*. This human gate is **permanent, not a manual-scope limitation** — the D2/D13 *agent-suggests-human-decides* pattern applied to the highest-blast-radius write in the system. **Authority is hard-bounded to the config / "learned behavior" layer** — skills, agent prompts, the intake rubric (D11), project rules — and **never the flow itself**: the status model (D4), the gates, and the structural decisions D1–D15 are off-limits. The dreamer may *raise* a suspected structural problem as a **parking-lot note for a human**, but must **not** propose structural changes as mergeable diffs. Improving *how* an agent does its job ≠ redesigning *the job*. **Deferred sub-item:** the human decider (D7 tiebreaker) and human merger (D13) are **not agents and do not auto-emit**, so the highest-value datum — *why a human overrode the machine* — is not captured by the emission step; capturing it is deferred (it would add friction to the human gate, and is a gate-mechanics detail, not framework shape).

## Rationale
The whole flow is a system of agents reading `.claude`; until now **nothing closed the loop on improving that config** — a linear pipeline with no feedback path. The dreamer adds that path, but it is structurally the **most dangerous component in the system**: it is the first phase that is asynchronous, cross-story, and **self-modifying** — it *writes the very files every other agent reads*, so a bad lesson silently degrades every future run rather than breaking one story. That blast radius is why it gets the **strictest** controls, not the loosest: the permanent human merge gate (it cannot change agent behavior without a human merging a PR), the cold-synthesis guarantee (warm self-grading must not decide what counts as a pattern), the one-PR-per-cycle shape (each change individually rejectable, auditable, and revertible — D5's resolvable-thread philosophy at the file level), and the hard authority boundary keeping it on the **config side of the D1–D15 line** (a self-improving agent that could rewrite its own gates is exactly the failure to design out). Emission is warm because the agent is the only thing that knows the *why* behind its iterations — artifacts show *that* the planner iterated three times, not *what it learned* — and the dreamer's coldness is precisely what keeps the synthesis of those warm reports honest.
