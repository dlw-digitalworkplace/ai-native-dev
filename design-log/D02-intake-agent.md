# D2 — Intake

- **Area:** Intake (phase 0)
- **Date:** 2026-06-17
- **Status:** Active

## Decision
An **intake agent** scores each user story *before* planning against a readiness rubric, writes its reasoning in ADO comments. It **suggests** fixes but does **not author** story content — the human authors the story/AC.

## Rationale
Catches vague stories before they burn downstream agent cycles; avoids polished-but-wrong AI-authored requirements.
